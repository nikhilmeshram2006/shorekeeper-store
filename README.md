## Overview

**SHOREKEEPER** is a clothing e-commerce website designed to provide a straightforward and enjoyable online shopping experience.

The project brings together a modern storefront, product browsing, shopping cart functionality and a checkout experience in one interface.

## Features

| Feature                | Description                                      |
| ---------------------- | ------------------------------------------------ |
| Product Catalog        | Browse available clothing products.              |
| Product Details        | View individual product information.             |
| Size & Color Selection | Choose product variations.                       |
| Shopping Cart          | Add and manage selected products.                |
| Coupon System          | Apply discount coupons.                          |
| User Accounts          | Sign-up and login interface.                     |
| Product Reviews        | View and interact with product reviews.          |
| Checkout               | Shopping checkout interface.                     |
| Local Storage          | Preserve supported shopping data in the browser. |

## Built With

- **HTML5** – Website structure.
- **CSS3** – Layout, styling and visual presentation.
- **JavaScript** – Interactive features and shopping functionality.
- **Local Storage** – Browser-side data persistence.
